
# University Management System

## Project Overview

The University Management System is a Java console-based application designed to manage university information, including students, courses, instructors, and student enrollments.

The system uses Object-Oriented Programming (OOP) principles and JDBC to connect Java applications with a PostgreSQL database.

## Features

- Add, view, search, update, and delete students.
- Manage university courses.
- Manage instructors.
- Enroll students in courses.
- View student enrollments.
- Retrieve enrollment information using SQL JOIN queries.
- Perform database transactions using COMMIT and ROLLBACK.
- Handle database operations using PreparedStatement.

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- PostgreSQL
- JDBC
- IntelliJ IDEA
- Git and GitHub

## Project Structure

- `model` - Contains Student, UndergraduateStudent, GraduateStudent, Course, and Instructor classes.
- `database` - Contains DatabaseConnection, StudentDAO, CourseDAO, and EnrollmentDAO.
- `Main.java` - Runs the University Management System console application.

## Database

The application uses PostgreSQL to store and manage university data.

Database tables include:
- Students
- Courses
- Enrollments

## How to Run

1. Install Java JDK.
2. Install PostgreSQL.
3. Configure the database connection.
4. Add the PostgreSQL JDBC driver.
5. Open the project in IntelliJ IDEA.
6. Run Main.java.

## Learning Objectives

This project demonstrates practical knowledge of Java OOP, inheritance, polymorphism, collections, JDBC, SQL queries, database management, and transaction handling.
